# Project_個人資訊網站

## 專案簡介與目的

這是一個個人資訊網站專案,用於展示個人簡介、經歷、作品與聯絡方式等資訊。

> 目前技術棧尚未定案,待確定後請補充「開發環境」與「安裝與執行方式」章節。

## 資料夾結構

```
src/
├── pages/            # 各頁面(例如首頁、關於我、作品集、聯絡我等)
├── public/            # 靜態資源,原樣輸出,不經打包處理(favicon、robots.txt 等)
├── scripts/           # JavaScript / TypeScript 邏輯
├── styles/             # CSS / 樣式檔案
├── assets/
│   ├── images/        # 圖片素材
│   └── fonts/         # 字型檔案
├── dist/               # 建置輸出目錄(由建置工具產生,不手動編輯)
├── package.json
├── .editorconfig
└── .gitignore
```

## 網頁開發習慣

- 縮排、換行等格式規則統一由 `.editorconfig` 管理,請確保編輯器有啟用對應套件。
- 檔案與資料夾命名採用小寫 + 連字號(kebab-case),例如 `about-me.html`。
- 樣式與腳本依頁面或元件拆分,避免單一檔案過度肥大。
- 圖片、字型等靜態資源統一放在 `assets/` 對應子資料夾,並使用相對路徑引用。
- commit message 建議簡潔描述變更內容(例如:`新增關於我頁面`、`修正導覽列在手機版的顯示問題`)。
